# turtle-programs
Programs I write for CC turtles in Minecraft.

These are *extremely* begginer level and are custom made for my world.

## General programs for turtles:
- hello -> A simple hello world.
- refuelYourself -> Turtle refuels herself with a Create lava Spout and a bucket.
- relocateBlock -> Moves 1 item from a chest to another.

## Programs for a mining turtle:
- areaMining ->  Mines a cubic area. Allows input.
- bigAreaMining -> Mines a 20x20 cubic area and dumps everything periodically into a chest.
- mineOne -> Mines the same block over and over, and when inventory is full dumps it into a chest. Perfect for stone generators.
- straightMining -> Mines a number of blocks in a straight line.
